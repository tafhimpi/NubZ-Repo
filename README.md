# Tafhim

Personal website of Tafhim. Plain HTML and CSS, no build step.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy

1. Push this repository to GitHub.
2. Import it at [vercel.com/new](https://vercel.com/new) and click **Deploy**.
3. Add your domain under **Settings → Domains**.

## Edit

- Content: `index.html`
- Colors and fonts: variables at the top of `style.css`
